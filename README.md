# Mother AI · JARVIS public demo

This folder is a standalone, static website for the Mother AI project overview and JARVIS visual prototype. It is designed for static hosting such as GitHub Pages.

## Contents

- `index.html` — overview of Mother AI, the JARVIS concept, and the prototype's current status.
- `demo.html` — interactive Chat and Work simulation.
- `site.css`, `jarvis.css`, `jarvis.js` — local styles and prototype behavior.

## What visitors can try

Visitors can enter an idea, review a starter-plan template, approve it, and watch a simulated timeline and preview update. The prototype does not use an AI, execute tasks, save entries, or send visitor data to a server. It has no build step or package dependencies.

## Publish with GitHub Pages

1. Create a public GitHub repository for the demo.
2. Add the files in this folder to the repository root.
3. Enable GitHub Pages for the repository's default branch and root folder in the repository's Pages settings.
4. Open the Pages URL GitHub displays after deployment.

This is a static showcase only. It does not contain the Mother AI Python server, database, API adapter, or credentials.
