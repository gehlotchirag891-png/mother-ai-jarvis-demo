# Mother AI · JARVIS demo

A lightweight, static prototype of the Mother AI project overview and its visual-first JARVIS workspace. It runs with plain HTML, CSS, and JavaScript; there is no build step and no package installation.

## Run it locally

1. Open this folder in VS Code.
2. Start a static preview using the Live Server extension if it is already available, or run `python -m http.server 8000` from this folder.
3. Open `http://localhost:8000/` in a browser. Select **Try the interactive demo** to open Chat and Work.

You can also open `index.html` directly in a modern browser. Browser storage behavior for local files can vary, so a local web preview is recommended when you want to check saved plans.

## What the prototype does

- Create multiple starter plans in Chat.
- Save and review them in the Work list.
- Switch between plans and continue their simulated progress.
- Keep plans and progress in the current browser using local storage.
- Remove one plan or clear all saved plans from Work.
- Pause an active simulation when switching plans or refreshing the page.
- Explore the JARVIS tab's golden orbital core and zoom controls.
- Type a request in JARVIS to create a local starter plan that appears in Work.

## Privacy and limits

Plan text and demo progress stay in the current browser profile. They are not uploaded, shared with other visitors, or synchronized between devices. Clearing browser site data removes them. If browser storage is unavailable, the page displays that plans will last only until it closes.

The plan template is local and is not generated by an AI. The JARVIS core is a visual animation; it does not access a microphone, record audio, or speak. The progress controls only simulate a visual walkthrough; they do not execute tasks. JARVIS has no computer access. This static site has no API, backend, background workers, or system automation.

## Files

- `index.html` — project overview.
- `demo.html` — the Chat and Work prototype.
- `site.css`, `jarvis.css`, `workspace.css`, `jarvis-core.css` — page, workspace, and orbital animation styles.
- `jarvis.js` — interface and local simulation behavior.
- `workspace-store.js` — versioned browser-storage helper.
